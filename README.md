## 制作実績

### きまログ

議事録から決定事項を抽出し、チームの質問に出典付きで答えるAIアシスタントです。4人チームで、PostgreSQLのデータベース設計と、議事録の確定・決定事項の取得API、検索用データの登録、Mastraの会話メモリとユーザー・チーム情報の連携を担当しました。

[リポジトリ](https://github.com/erina24/kimarogu-public) · [DB設計](https://github.com/erina24/kimarogu-public/blob/main/docs/database.md) · [API仕様](https://github.com/erina24/kimarogu-public/blob/main/docs/api.md)

### 札幌防災マップ

個人制作です。札幌市のオープンデータを使い、指定避難所4か所を地図で確認できるWeb GISの試作です。施設名や区で絞り込んだ結果が、地図のマーカーと一覧の両方に反映されるように実装しました。

[公開デモ](https://sapporo-shelter-map.vercel.app) · [リポジトリ](https://github.com/erina24/sapporo-shelter-map)

### KOKYU Pilates CMS

個人制作です。スタジオスタッフが、お知らせ・インストラクター紹介・体験レッスンの料金をmicroCMSから更新できるWebサイトのデモです。スタジオ運営の経験をもとに、更新する項目を設計し、スタッフ向けに公開手順をまとめました。

[公開デモ](https://pilates-studio-site-two.vercel.app/) · [体験レッスンの料金ページ](https://pilates-studio-site-two.vercel.app/plans)
